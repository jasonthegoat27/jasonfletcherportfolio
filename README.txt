How to use:
1. Upload this whole folder to GitHub or Netlify.
2. Netlify build command: npm run build
3. Netlify publish directory: dist
4. The real images are already inside public/images.
5. If you want real Equinox/Inklings previews, export those slides as PNGs and replace:
   public/images/equinox-work-sample.svg
   public/images/inklings-work-sample.svg
